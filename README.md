# Johnstheward S. Alvarado

Personal website for employers, live at **https://jsalvarado.github.io**.

Plain HTML, CSS and JavaScript with no build step:

- `index.html`: all the content (experience, FLOATech, skills, recognition, goals, contact)
- `style.css`: colors and fonts are tokens at the top in `:root`; dark mode is automatic
- `script.js`: mobile menu, active-section highlighting, scroll fade-in, copy-email button, photo lightbox

Photos load from the `images/` folder of the
[PortFolio](https://github.com/JSAlvarado/PortFolio) repo (`/PortFolio/images/...`),
so keep those files there or copy them into this repo and update the paths.

To update the site, edit `index.html` and commit to `main`. GitHub Pages republishes in a minute or two.
