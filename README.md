# Johnstheward S. Alvarado

Personal website for employers, live at **https://jsalvarado.github.io**.

Plain HTML, CSS and JavaScript with no build step:

- `index.html`: all the content (about, experience, projects, skills, recognition, goals, contact)
- `style.css`: seven color tokens, spacing and fonts at the top in `:root`; mobile-first (640px, 960px)
- `script.js`: mobile menu, active-section highlighting, scroll fade-in, copy-email button, photo lightbox
- `assets/`: every photo, logo and the resume PDF the page uses

To update the site, edit `index.html` and commit to `main`. GitHub Pages republishes in a minute or two.
