## Features

- **Editorial, print-style design** with scroll-linked motion: each block fades and rises in step with the scroll,
  and photos fill from grayscale to colour as they come into view. Everything appears at once under *Reduce motion*.
- **Animated FLOATech drawing:** an SVG of the unit on a pond (bobbing, feeding, microbubble aeration, signal from
  the GSM antenna) that plays only while it is on screen.
- **Portfolio Q&A chatbot:** a draggable floating assistant that answers questions about John from approved answers
  only. Keyword matching with typo tolerance (edit distance), word-form handling and privacy rules that are checked
  first. No AI and no network calls: questions never leave the browser.
- **English / Korean switch:** the whole page and every chatbot answer in Korean, with names, job titles and award
  rankings kept in English.
- **Accessible and responsive:** semantic HTML, keyboard navigation, visible focus, WCAG AA contrast, layouts tested
  from 360px phones to desktop.
- **Privacy-friendly visitor counting** with GoatCounter (no cookies).

## Built with

Plain **HTML, CSS and JavaScript**, no framework and no build step, hosted on **GitHub Pages**.
Built with the help of **Claude Code** (AI-assisted development).
