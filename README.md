# Johnstheward S. Alvarado

Personal website for employers, live at **https://jsalvarado.github.io**.

Plain HTML, CSS and JavaScript with no build step:

- `index.html`: all the content, in order: About, FLOATech, Other projects, Skills, Experience, Awards, Education, Career roadmap, Contact
- `style.css`: seven color tokens, spacing and fonts at the top in `:root`; mobile-first (640px, 960px)
- `script.js`: mobile menu, active-section highlighting, scroll-linked reveal and photo color, copy-email button, photo viewer
- `assets/`: every photo, logo and the resume PDF the page uses

To update the site, edit the files, commit to `main` and push. GitHub Pages republishes in a minute or two.
